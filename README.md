# Monty Hall problem - website simulation

interactive simulation for **visualizing the Monty Hall problem** and seeing why switching doors gives you better odds.

**[live demo](https://akers4i.github.io/monty-hall_simulation/)**

## about

run simulations and compare the two strategies:

* **stay:** ~33.3% win rate
* **switch:** ~66.7% win rate
